# Fase 2 — Loja: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Colocar a vitrine no ar no app novo: catálogo migrado do formato antigo, home, página de produto, página de coleção, páginas legais, SEO (metadados, JSON-LD, sitemap e robots) e carrinho em gaveta lateral com preços sempre calculados no servidor. No fim, remover o app antigo (`legacy/`).

**Architecture:** O catálogo é lido só no servidor (Admin SDK), validado por schemas zod em `src/lib/catalog-schemas.ts` e servido às páginas por leitores em cache (`unstable_cache`, tag `catalog`, revalidação de 1 h) que devolvem objetos simples (datas como texto). As páginas da loja ficam no grupo de rotas `(loja)`, com cabeçalho, rodapé e carrinho. O carrinho guarda só `{ productId, size, color, qty }` no `localStorage`; nome, imagem e preço vêm da Server Action `priceCartAction`, que remove itens inválidos.

**Tech Stack:** Next.js 16 (App Router, ISR com `unstable_cache`), React 19, TypeScript 5.9, Tailwind v4, zod 4, firebase-admin 14, Vitest 5 + Testing Library, emulador do Firestore.

**Spec:** `docs/superpowers/specs/2026-10-02-redesign-nextjs-design.md`

## Global Constraints

- Tudo da Fase 1 continua valendo: TypeScript strict com `noUncheckedIndexedAccess`, alias `@/*`, `server-only` em `src/server/**`, dinheiro em centavos (`Cents`), mensagens em português, `Result<T>` para erros esperados, Conventional Commits em inglês sem atribuição a IA, sem `git push`.
- Só o servidor lê o Firestore. Componentes de cliente recebem dados por props ou Server Actions.
- Dados que passam por `unstable_cache` não podem conter `Date`: usar os tipos `Store*` (datas em ISO string).
- Toda página da loja exporta `revalidate = 3600` e usa leitores com a tag `catalog` (o admin da Fase 5 chamará `revalidateTag('catalog', 'max')`).
- Imagens com `next/image` e o loader do Cloudinary (`src/lib/cloudinary-loader.ts`).
- Não exibir parcelamento ("6x sem juros"): o Checkout Pro cobra juros conforme a configuração do Mercado Pago, e a promessa seria falsa.
- Produção sob demanda: prazo padrão de produção dos produtos migrados = **10 dias úteis**.
- Pesos padrão na migração: camiseta 250 g, moletom 700 g, boné 150 g, touca 120 g, demais 300 g.
- Links de seção usam âncoras nativas (`/#shop`, `/#colecoes`, `/#manifesto`, `/#sobre`, `/#contato`) com `scroll-margin-top`; nada de rolagem por JavaScript.
- Testes de emulador rodam com `make test-emulator`; o PATH desta máquina precisa do JDK (`C:\Program Files\Microsoft\jdk-21.0.12.101-hotspot\bin`) ou do Docker aberto.
- Branch de trabalho: `refactor/nextjs`.

## Review Focus

1. **Carrinho adulterado ou corrompido no `localStorage`** (JSON inválido, `qty: 999`, produto inexistente, cor que o produto não tem): a loja não pode quebrar; o carrinho limpa o que é inválido e o preço exibido sempre vem do servidor. Testado nas Tasks 6 e 7.
2. **Produto em rascunho, arquivado ou com slug inexistente:** nunca aparece na vitrine, responde 404 na página e é removido do carrinho. Testado nas Tasks 2 e 7.
3. **Produto sem cores (ou cor sem imagem própria) e tamanho único `UN`:** dá para adicionar ao carrinho sem escolher cor, e a galeria funciona. Testado na Task 11.
4. **Nome ou descrição de produto com `</script>`:** o JSON-LD não pode quebrar a página nem injetar script. Testado na Task 10.
5. **Projeto sem o documento `settings/store` ou com WhatsApp vazio:** o site renderiza com padrões e esconde o botão de WhatsApp. Testado nas Tasks 2 e 9.

```ts
export const CATEGORIES = ['SUPERIORES', 'INFERIORES', 'ACESSÓRIOS', 'CONJUNTOS'] as const
export type Category = (typeof CATEGORIES)[number]

export function slugify(input: string): string {
  return input
    .normalize('NFD')
    .replace(/[\u0300-\u036f]/g, '')
    .toLowerCase()
    .replace(/['"]/g, '')
    .replace(/[^a-z0-9]+/g, '-')
    .replace(/^-+|-+$/g, '')
}

const time = (value: Date | string) => new Date(value).getTime()

/** Destaques primeiro (featuredOrder crescente); o resto do mais antigo para o mais novo. */
export function sortForShop<
  T extends { featured: boolean; featuredOrder: number | null; createdAt: Date | string },
>(items: T[]): T[] {
  return [...items].sort((a, b) => {
    if (a.featured !== b.featured) return a.featured ? -1 : 1
    if (a.featured && b.featured) {
      return (a.featuredOrder ?? Number.MAX_SAFE_INTEGER) - (b.featuredOrder ?? Number.MAX_SAFE_INTEGER)
    }
    return time(a.createdAt) - time(b.createdAt)
  })
}
```

`src/lib/cloudinary.ts`:

```ts
const HOST = 'https://res.cloudinary.com/'
const UPLOAD = '/upload/'
const TRANSFORMATION = /^[a-z]{1,3}_[^/,]+(,[a-z]{1,3}_[^/,]+)*$/

export function isCloudinaryUrl(url: string): boolean {
  return url.startsWith(HOST) && url.includes(UPLOAD)
}

function splitUpload(url: string): [string, string[]] {
  const index = url.indexOf(UPLOAD)
  const segments = url.slice(index + UPLOAD.length).split('/')
  // Remove segmentos de transformação do começo, mas nunca o último (o arquivo).
  while (segments.length > 1 && TRANSFORMATION.test(segments[0] ?? '')) segments.shift()
  return [url.slice(0, index), segments]
}

export function cloudinaryUrl(
  url: string,
  {
    width,
    format = 'auto',
    quality = 'auto',
  }: { width?: number; format?: 'auto' | 'jpg'; quality?: 'auto' | number } = {},
): string {
  if (!isCloudinaryUrl(url)) return url
  const [base, segments] = splitUpload(url)
  const transformations = [`f_${format}`, `q_${quality}`, 'c_limit', ...(width ? [`w_${width}`] : [])]
  return `${base}${UPLOAD}${transformations.join(',')}/${segments.join('/')}`
}

export function cloudinaryPublicId(url: string): string {
  const [, segments] = splitUpload(url)
  if (/^v\d+$/.test(segments[0] ?? '') && segments.length > 1) segments.shift()
  return segments.join('/').replace(/\.[a-z0-9]+$/i, '')
}
```

```ts
import 'server-only'
import { productSchema, type ProductDoc } from '@/lib/catalog-schemas'
import { zodConverter } from './convert'
import { db } from './firebase-admin'

export type Product = ProductDoc & { id: string }
```

```ts
// Imports relativos: roda tanto no Vitest quanto no tsx, fora do Next.
import { slugify } from '../../src/lib/catalog'
import { productSchema, type ProductDoc } from '../../src/lib/catalog-schemas'
import { cloudinaryPublicId } from '../../src/lib/cloudinary'
import { toCents } from '../../src/lib/money'

export const DEFAULT_PRODUCTION_DAYS = 10

export type LegacyProduct = {
  name: string
  price: number
  description?: string
  category: string
  sizes?: string[]
  colors?: { name: string; hex: string; img?: string | null }[]
  details?: string[]
  features?: string[]
  measurements?: { columns: string[]; rows: { size: string; values: string[] }[] } | null
  img?: string
  gallery?: string[]
  isActive?: boolean
  isFeatured?: boolean
  created_at?: Date
  updated_at?: Date
}

const WEIGHTS: [RegExp, number][] = [
  [/hoodie|moletom/i, 700],
  [/t-?shirt|camiseta/i, 250],
  [/\bcap\b|bon[eé]/i, 150],
  [/beanie|touca/i, 120],
]

export function estimateWeightGrams(name: string): number {
  return WEIGHTS.find(([pattern]) => pattern.test(name))?.[1] ?? 300
}

export function isMigrated(doc: Record<string, unknown>): boolean {
  return typeof doc.priceCents === 'number'
}

export function uniqueSlugs(names: string[]): string[] {
  const seen = new Map<string, number>()
  return names.map((name) => {
    const base = slugify(name)
    const count = (seen.get(base) ?? 0) + 1
    seen.set(base, count)
    return count === 1 ? base : `${base}-${count}`
  })
}

const clean = (items: string[] | undefined) => (items ?? []).map((s) => s.trim()).filter(Boolean)

export function migrateProduct(
  legacy: LegacyProduct,
  context: { slug: string; featuredOrder: number | null; now: Date },
): ProductDoc {
  const urls = [...new Set([legacy.img, ...(legacy.gallery ?? [])].filter((u): u is string => !!u))]
  const details = clean(legacy.details)

  return productSchema.parse({
    slug: context.slug,
    name: legacy.name.trim(),
    description: legacy.description?.trim() ?? '',
    category: legacy.category,
    priceCents: toCents(legacy.price),
    weightGrams: estimateWeightGrams(legacy.name),
    productionDays: DEFAULT_PRODUCTION_DAYS,
    sizes: legacy.sizes ?? [],
    colors: (legacy.colors ?? []).map((color) => ({
      name: color.name,
      hex: color.hex,
      image: color.img ?? null,
    })),
    images: urls.map((url, index) => ({
      url,
      publicId: cloudinaryPublicId(url),
      alt: `${legacy.name.trim()} — foto ${index + 1}`,
    })),
    highlights: details.length > 0 ? details : clean(legacy.features),
    sizeGuide: legacy.measurements ?? null,
    collectionIds: [],
    status: legacy.isActive ? 'active' : 'draft',
    featured: legacy.isFeatured === true,
    featuredOrder: context.featuredOrder,
    createdAt: legacy.created_at ?? context.now,
    updatedAt: context.now,
  })
}
```

```ts
// Migra o catálogo do app antigo para o formato novo, no mesmo projeto Firebase.
// Uso: npm run migrate-catalog            (só mostra o que faria)
//      npm run migrate-catalog -- --apply (faz backup em .backups/ e grava)
import { mkdirSync, writeFileSync } from 'node:fs'
import { cert, initializeApp } from 'firebase-admin/app'
import { getFirestore, Timestamp } from 'firebase-admin/firestore'
import { formatBRL } from '../src/lib/money'
import { DEFAULT_STORE_SETTINGS } from '../src/lib/store-settings'
import { isMigrated, migrateProduct, uniqueSlugs, type LegacyProduct } from './lib/catalog-migration'
import { LEGACY_COLLECTIONS } from './lib/legacy-collections'

function toPlain(value: unknown): unknown {
  if (value instanceof Timestamp) return value.toDate()
  if (Array.isArray(value)) return value.map(toPlain)
  if (value && typeof value === 'object') {
    return Object.fromEntries(Object.entries(value).map(([k, v]) => [k, toPlain(v)]))
  }
  return value
}

async function main() {
  const apply = process.argv.includes('--apply')
  const { FIREBASE_PROJECT_ID, FIREBASE_CLIENT_EMAIL, FIREBASE_PRIVATE_KEY } = process.env
  if (!FIREBASE_PROJECT_ID || !FIREBASE_CLIENT_EMAIL || !FIREBASE_PRIVATE_KEY) {
    throw new Error('Defina FIREBASE_PROJECT_ID, FIREBASE_CLIENT_EMAIL e FIREBASE_PRIVATE_KEY no .env.local')
  }
  initializeApp({
    credential: cert({
      projectId: FIREBASE_PROJECT_ID,
      clientEmail: FIREBASE_CLIENT_EMAIL,
      privateKey: FIREBASE_PRIVATE_KEY.replace(/\\n/g, '\n'),
    }),
  })
  const db = getFirestore()
  const now = new Date()

  const snapshot = await db.collection('products').get()
  const pending = snapshot.docs.filter((doc) => !isMigrated(doc.data()))
  const legacy = pending.map((doc) => ({ id: doc.id, data: toPlain(doc.data()) as LegacyProduct }))
  const slugs = uniqueSlugs(legacy.map((item) => item.data.name))
  let featuredCount = 0

  const migrated = legacy.map((item, index) => {
    const featuredOrder = item.data.isFeatured ? featuredCount++ : null
    const doc = migrateProduct(item.data, { slug: slugs[index] ?? '', featuredOrder, now })
    return { id: item.id, doc }
  })

  console.log(`Projeto: ${FIREBASE_PROJECT_ID}`)
  console.log(`Produtos já no formato novo: ${snapshot.size - pending.length}`)
  console.table(
    migrated.map(({ id, doc }) => ({
      id,
      slug: doc.slug,
      preço: formatBRL(doc.priceCents),
      status: doc.status,
      peso: `${doc.weightGrams} g`,
      imagens: doc.images.length,
    })),
  )
  console.log(`Coleções: ${LEGACY_COLLECTIONS.map((c) => `${c.slug} (${c.status})`).join(', ')}`)

  if (!apply) {
    console.log('\nSimulação: nada foi gravado. Rode com --apply para gravar.')
    return
  }

  mkdirSync('.backups', { recursive: true })
  const backupFile = `.backups/catalog-${now.toISOString().replace(/[:.]/g, '-')}.json`
  writeFileSync(
    backupFile,
    JSON.stringify(snapshot.docs.map((doc) => ({ id: doc.id, data: toPlain(doc.data()) })), null, 2),
  )
  console.log(`Backup dos produtos atuais: ${backupFile}`)

  const batch = db.batch()
  for (const { id, doc } of migrated) batch.set(db.collection('products').doc(id), doc)
  for (const collection of LEGACY_COLLECTIONS) {
    batch.set(db.collection('collections').doc(collection.slug), collection)
  }
  const settingsRef = db.doc('settings/store')
  if (!(await settingsRef.get()).exists) batch.set(settingsRef, DEFAULT_STORE_SETTINGS)
  await batch.commit()

  console.log(`✓ ${migrated.length} produto(s) e ${LEGACY_COLLECTIONS.length} coleção(ões) gravados.`)
}

main().catch((error) => {
  console.error(error)
  process.exit(1)
})
```

```ts
import { z } from 'zod'

export const MAX_QTY = 10
export const MAX_LINES = 30
export const CART_STORAGE_KEY = 'streetstars:cart:v2'

export type CartLine = { productId: string; size: string; color: string | null; qty: number }

const lineSchema = z.object({
  productId: z.string().min(1).max(64),
  size: z.string().min(1).max(20),
  color: z.string().min(1).max(40).nullable(),
  qty: z.number().int(),
})

const clampQty = (qty: number) => Math.min(MAX_QTY, Math.max(0, Math.trunc(qty)))

export function lineKey(line: Pick<CartLine, 'productId' | 'size' | 'color'>): string {
  return `${line.productId}|${line.size}|${line.color ?? ''}`
}

export function addLine(lines: CartLine[], item: Omit<CartLine, 'qty'>, qty = 1): CartLine[] {
  const key = lineKey(item)
  const existing = lines.find((line) => lineKey(line) === key)
  if (!existing) return [...lines, { ...item, qty: clampQty(qty) }]
  return lines.map((line) =>
    lineKey(line) === key ? { ...line, qty: clampQty(line.qty + qty) } : line,
  )
}

export function setLineQty(lines: CartLine[], key: string, qty: number): CartLine[] {
  const next = clampQty(qty)
  if (next < 1) return removeLine(lines, key)
  return lines.map((line) => (lineKey(line) === key ? { ...line, qty: next } : line))
}

export function removeLine(lines: CartLine[], key: string): CartLine[] {
  return lines.filter((line) => lineKey(line) !== key)
}

/** Aceita qualquer coisa vinda do navegador e devolve só linhas válidas, sem repetição. */
export function sanitizeLines(raw: unknown): CartLine[] {
  if (!Array.isArray(raw)) return []
  let lines: CartLine[] = []
  for (const item of raw) {
    const parsed = lineSchema.safeParse(item)
    if (!parsed.success || parsed.data.qty < 1) continue
    lines = addLine(lines, parsed.data, parsed.data.qty)
  }
  return lines.slice(0, MAX_LINES)
}

export function parseCart(raw: string | null): CartLine[] {
  if (!raw) return []
  try {
    return sanitizeLines(JSON.parse(raw))
  } catch {
    return []
  }
}

export function serializeCart(lines: CartLine[]): string {
  return JSON.stringify(lines)
}

export function cartCount(lines: CartLine[]): number {
  return lines.reduce((total, line) => total + line.qty, 0)
}
```

```ts
import 'server-only'
import { lineKey, MAX_QTY, type CartLine } from '@/lib/cart'
import type { Product } from '@/server/db/products'

export type PricedLine = {
  key: string
  productId: string
  slug: string
  name: string
  image: string
  size: string
  color: string | null
  unitPriceCents: number
  qty: number
  lineTotalCents: number
}

export type PricedCart = { lines: PricedLine[]; removedKeys: string[]; subtotalCents: number }

type PricingProduct = Pick<
  Product,
  'id' | 'slug' | 'name' | 'priceCents' | 'sizes' | 'colors' | 'images' | 'status'
>

export function priceLines(lines: CartLine[], products: PricingProduct[]): PricedCart {
  const byId = new Map(products.map((product) => [product.id, product]))
  const priced: PricedLine[] = []
  const removedKeys: string[] = []

  for (const line of lines) {
    const key = lineKey(line)
    const product = byId.get(line.productId)
    const color = product?.colors.find((c) => c.name === line.color)
    const colorOk = product ? (product.colors.length === 0 ? line.color === null : !!color) : false

    if (!product || product.status !== 'active' || !product.sizes.includes(line.size) || !colorOk) {
      removedKeys.push(key)
      continue
    }

    const qty = Math.min(MAX_QTY, line.qty)
    priced.push({
      key,
      productId: product.id,
      slug: product.slug,
      name: product.name,
      image: color?.image ?? product.images[0]?.url ?? '',
      size: line.size,
      color: line.color,
      unitPriceCents: product.priceCents,
      qty,
      lineTotalCents: product.priceCents * qty,
    })
  }

  return {
    lines: priced,
    removedKeys,
    subtotalCents: priced.reduce((total, line) => total + line.lineTotalCents, 0),
  }
}
```

```ts
'use server'

import { sanitizeLines } from '@/lib/cart'
import { getProductsByIds } from '@/server/db/products'
import { priceLines, type PricedCart } from '@/server/domain/cart-pricing'
import { clientIp, rateLimit } from '@/server/ratelimit'

const EMPTY: PricedCart = { lines: [], removedKeys: [], subtotalCents: 0 }

export async function priceCartAction(rawLines: unknown): Promise<PricedCart> {
  const lines = sanitizeLines(rawLines)
  if (lines.length === 0) return EMPTY
  if (!(await rateLimit(`cart:${await clientIp()}`, { limit: 60, windowSec: 60 }))) {
    throw new Error('Muitas requisições. Tente novamente em instantes.')
  }
  const products = await getProductsByIds(lines.map((line) => line.productId))
  return priceLines(lines, products)
}
```

- [ ] **Step 2: Implementar o contexto**

O carrinho vive no `localStorage` e é lido com `useSyncExternalStore`: o servidor renderiza um carrinho vazio, o cliente lê o armazenamento sem `setState` dentro de efeitos (proibido pela regra `react-hooks/set-state-in-effect`) e abas diferentes ficam sincronizadas pelo evento `storage`.

`src/features/cart/cart-context.tsx`:

```tsx
'use client'

import { createContext, use, useCallback, useMemo, useState, useSyncExternalStore } from 'react'
import {
  addLine,
  CART_STORAGE_KEY,
  cartCount,
  parseCart,
  removeLine,
  serializeCart,
  setLineQty,
  type CartLine,
} from '@/lib/cart'

type CartContextValue = {
  lines: CartLine[]
  count: number
  isOpen: boolean
  open: () => void
  close: () => void
  add: (item: Omit<CartLine, 'qty'>, qty?: number) => void
  setQty: (key: string, qty: number) => void
  remove: (key: string) => void
  removeKeys: (keys: string[]) => void
}

const CartContext = createContext<CartContextValue | null>(null)

// ── Armazenamento: localStorage, ou memória se o navegador bloquear ──────────
const listeners = new Set<() => void>()
let memory: string | null = null

function readRaw(): string | null {
  try {
    return localStorage.getItem(CART_STORAGE_KEY)
  } catch {
    return memory
  }
}

function writeLines(lines: CartLine[]) {
  const raw = serializeCart(lines)
  try {
    localStorage.setItem(CART_STORAGE_KEY, raw)
  } catch {
    memory = raw
  }
  listeners.forEach((listener) => listener())
}

function subscribe(listener: () => void) {
  listeners.add(listener)
  const onStorage = (event: StorageEvent) => {
    if (event.key === CART_STORAGE_KEY) listener()
  }
  window.addEventListener('storage', onStorage)
  return () => {
    listeners.delete(listener)
    window.removeEventListener('storage', onStorage)
  }
}

const serverSnapshot = () => null

function update(change: (lines: CartLine[]) => CartLine[]) {
  const current = parseCart(readRaw())
  const next = change(current)
  if (serializeCart(next) !== serializeCart(current)) writeLines(next)
}

export function CartProvider({ children }: { children: React.ReactNode }) {
  const raw = useSyncExternalStore(subscribe, readRaw, serverSnapshot)
  const lines = useMemo(() => parseCart(raw), [raw])
  const [isOpen, setIsOpen] = useState(false)

  const add = useCallback((item: Omit<CartLine, 'qty'>, qty = 1) => {
    update((current) => addLine(current, item, qty))
    setIsOpen(true)
  }, [])
  const setQty = useCallback((key: string, qty: number) => {
    update((current) => setLineQty(current, key, qty))
  }, [])
  const remove = useCallback((key: string) => {
    update((current) => removeLine(current, key))
  }, [])
  const removeKeys = useCallback((keys: string[]) => {
    update((current) => keys.reduce(removeLine, current))
  }, [])

  const value = useMemo<CartContextValue>(
    () => ({
      lines,
      count: cartCount(lines),
      isOpen,
      open: () => setIsOpen(true),
      close: () => setIsOpen(false),
      add,
      setQty,
      remove,
      removeKeys,
    }),
    [lines, isOpen, add, setQty, remove, removeKeys],
  )

  return <CartContext value={value}>{children}</CartContext>
}

export function useCart(): CartContextValue {
  const cart = use(CartContext)
  if (!cart) throw new Error('useCart deve ser usado dentro de CartProvider')
  return cart
}
```

```tsx
    alternates: { canonical: `/legal/${slug}` },
    robots: { index: false, follow: true },
  }
}

export default async function LegalPage({ params }: { params: Promise<{ slug: string }> }) {
  const { slug } = await params

  const page = LEGAL_PAGES[slug]

  const siteHost = new URL(publicEnv().NEXT_PUBLIC_SITE_URL).host

      <h1 className="mb-8 border-b border-line pb-6 text-3xl font-black uppercase italic md:text-5xl">
        {page.title}
```

```tsx
            key={category}

            onClick={() => setFilter(category)}
            className={cn(

            {category}
          </button>
        ))}

        {visible.map((product) => (
          <ProductCard key={product.id} product={product} />
        ))}
      </div>
    </div>
  )
}
```

```ts
import type { ProductDoc } from './catalog-schemas'
import { cloudinaryUrl } from './cloudinary'

export function productJsonLd(
  product: Pick<ProductDoc, 'name' | 'slug' | 'description' | 'priceCents' | 'images'>,
  siteUrl: string,
): Record<string, unknown> {
  const url = `${siteUrl}/produto/${product.slug}`
  return {
    '@context': 'https://schema.org',
    '@type': 'Product',
    name: product.name,
    description: product.description,
    image: product.images.map((image) => cloudinaryUrl(image.url, { width: 1200, format: 'jpg' })),
    brand: { '@type': 'Brand', name: 'Street Stars' },
    offers: {
      '@type': 'Offer',
      price: (product.priceCents / 100).toFixed(2),
      priceCurrency: 'BRL',
      availability: 'https://schema.org/InStock',
      itemCondition: 'https://schema.org/NewCondition',
      url,
    },
  }
}
```

```tsx
'use client'

import Image from 'next/image'
import { useCallback, useEffect, useRef, useState } from 'react'
import { cn } from '@/lib/cn'

export function ProductGallery({
  images,
  activeUrl,
}: {
  images: { url: string; alt: string }[]
  activeUrl?: string | null
}) {
  const ref = useRef<HTMLDivElement>(null)
  const [index, setIndex] = useState(0)

  const goTo = useCallback((target: number) => {
    const slider = ref.current
    if (!slider) return
    slider.scrollTo({ left: target * slider.clientWidth, behavior: 'smooth' })
  }, [])

  // Só rola quando a cor escolhida muda (a URL é o que importa, não a identidade do array).
  useEffect(() => {
    if (!activeUrl) return
    const target = images.findIndex((image) => image.url === activeUrl)
    if (target >= 0) goTo(target)
    // eslint-disable-next-line react-hooks/exhaustive-deps
  }, [activeUrl, goTo])

  return (
    <div className="relative">
      <div
        ref={ref}
        role="region"
        aria-label="Fotos do produto"
        tabIndex={0}
        onScroll={(event) => {
          const slider = event.currentTarget
          setIndex(Math.round(slider.scrollLeft / slider.clientWidth))
        }}
        className="flex aspect-[4/5] snap-x snap-mandatory overflow-x-auto bg-surface [scrollbar-width:none] lg:aspect-auto lg:h-[85vh]"
      >
        {images.map((image, i) => (
          <div key={image.url} className="relative h-full w-full shrink-0 snap-start">
            <Image
              src={image.url}
              alt={image.alt}
              fill
              sizes="(max-width: 1024px) 100vw, 50vw"
              loading={i === 0 ? 'eager' : 'lazy'}
              fetchPriority={i === 0 ? 'high' : 'auto'}
              className="object-cover"
            />
          </div>
        ))}
      </div>
      {images.length > 1 ? (
        <div className="absolute inset-x-0 bottom-6 flex justify-center gap-2">
          {images.map((image, i) => (
            <button
              key={image.url}
              type="button"
              aria-label={`Ver foto ${i + 1}`}
              aria-current={index === i ? 'true' : undefined}
              onClick={() => goTo(i)}
              className="p-2"
            >
              <span className={cn('block size-1.5 rounded-full', index === i ? 'bg-paper' : 'bg-paper/30')} />
            </button>
          ))}
        </div>
      ) : null}
    </div>
  )
}
```

`src/lib/seo.ts`:

```ts
import type { MetadataRoute } from 'next'

export function buildSitemap(
  siteUrl: string,
  input: {
    products: { slug: string; updatedAt: string }[]
    collections: { slug: string }[]
    legalSlugs: string[]
  },
): MetadataRoute.Sitemap {
  return [
    { url: `${siteUrl}/`, changeFrequency: 'weekly', priority: 1 },
    ...input.products.map((product) => ({
      url: `${siteUrl}/produto/${product.slug}`,
      lastModified: product.updatedAt,
      changeFrequency: 'weekly' as const,
      priority: 0.8,
    })),
    ...input.collections.map((collection) => ({
      url: `${siteUrl}/colecao/${collection.slug}`,
      changeFrequency: 'monthly' as const,
      priority: 0.7,
    })),
    ...input.legalSlugs.map((slug) => ({
      url: `${siteUrl}/legal/${slug}`,
      changeFrequency: 'yearly' as const,
      priority: 0.2,
    })),
  ]
}

export function buildRobots(siteUrl: string): MetadataRoute.Robots {
  return {
    rules: {
      userAgent: '*',
      allow: '/',
      disallow: ['/admin', '/conta', '/checkout', '/pedido', '/entrar'],
    },
    sitemap: `${siteUrl}/sitemap.xml`,
  }
}
```
