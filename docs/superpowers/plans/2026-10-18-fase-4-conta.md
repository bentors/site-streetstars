# Fase 4 — Conta do cliente: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Área do cliente completa: cadastro com verificação de e-mail, recuperação de senha, `/conta` com pedidos, endereços, perfil e troca de senha, vínculo automático de pedidos feitos sem login, e checkout que usa e salva os endereços da conta.

**Architecture:** As regras de endereço (um único padrão, limite, deduplicação) são funções puras em `src/server/domain/addresses.ts` (TDD). Os schemas de entrada ficam em `src/lib/account.ts`, usados tanto pelos formulários quanto pelas Server Actions. O repositório `src/server/db/users.ts` aplica toda mudança de perfil numa transação (lê, decide, grava o documento inteiro). Senha, cadastro e e-mails de verificação e de recuperação usam o Firebase Auth no navegador (`firebase/auth`, persistência em memória) e terminam sempre trocando o ID token por um session cookie (`signInAction`/`signUpAction`). O vínculo guest → conta acontece dentro de `createSession` quando o token diz que o e-mail é verificado. Assim, login com Google, login depois de confirmar o e-mail e renovação de sessão passam todos pelo mesmo ponto.

**Tech Stack:** Next.js 16 (App Router, Server Actions), React 19, TypeScript 5.9, zod 4, firebase 12 (`firebase/auth` no navegador), firebase-admin 14 (Auth + Firestore), Vitest 5 + Testing Library + emulador do Firestore. Nenhuma dependência nova.

**Spec:** `docs/superpowers/specs/2026-10-02-redesign-nextjs-design.md` (seções 2, 3, 5, 7 e 9)

## Global Constraints

- Tudo das Fases 1–3 continua valendo: TypeScript strict com `noUncheckedIndexedAccess`, alias `@/*`, `server-only` em `src/server/**`, mensagens ao usuário em português e sem detalhe interno, `Result<T>` (`ok`/`fail` de `@/lib/result`) para erros esperados, Conventional Commits em inglês sem atribuição a IA, sem `git push`.
- Lint do projeto: proibido `setState` síncrono dentro de `useEffect` (`react-hooks/set-state-in-effect`) e `new Date()`/`Date.now()` direto no corpo de componentes. Padrão aceito: `setState` depois de um `await` dentro de `startTransition`.
- Firestore não aceita `undefined`. Em transações, todas as leituras vêm antes de qualquer escrita.
- **Só o servidor lê e grava o Firestore.** No navegador, o Firebase serve só para autenticar (`clientAuth()`), e toda tela termina chamando uma Server Action.
- **Toda Server Action da conta chama `requireUser()`** e só toca `users/{uid}` do próprio uid (spec, seção 5).
- **Senha (spec):** mínimo de 8 caracteres, com letra e número. O formulário valida com `passwordProblem()`. O Firebase precisa ter a mesma política ativa no console para valer também no servidor (passo manual da Task 13).
- **Vínculo de pedidos (spec):** só com e-mail **verificado**, apenas pedidos com `customer.uid == null` e o mesmo e-mail (pedidos guardam o e-mail em minúsculas).
- **Endereços:** no máximo **10** por conta (`MAX_ADDRESSES`). Com um ou mais endereços, existe **exatamente um** `isDefault`, garantido no servidor.
- **Checkout logado (decisão do usuário, 2026-10-18):** pré-preenche com o endereço padrão, permite trocar entre os salvos e tem o checkbox "Salvar este endereço na minha conta". Telefone e CPF do checkout vão para o perfil **só se estiverem vazios lá**. Salvar dados da conta nunca faz o pedido falhar.

## Review Focus

1. **Cookie desatualizado depois de confirmar o e-mail:** o session cookie guarda `email_verified` do momento do login. Quem confirma o e-mail com a sessão aberta continua vendo o aviso. O botão "Já confirmei" consulta o Firebase, encerra a sessão e manda para `/entrar?confirmado=1`, e o novo login vincula os pedidos. Se o e-mail ainda não foi confirmado, aparece uma mensagem e a sessão continua. Testado na Task 7.
2. **Vínculo com e-mail em maiúsculas ou não verificado:** conta `Ana@Exemplo.com` verificada vincula o pedido guest `ana@exemplo.com`. Conta não verificada não vincula nada. Pedido que já é de outra conta não muda de dono. Falha no vínculo não impede o login. Testado na Task 4.
3. **Excluir, editar ou desmarcar o endereço padrão, ou passar do limite:** sempre sobra exatamente um padrão enquanto houver endereços, o 11º é recusado com mensagem, e editar um id que não existe mais dá "não encontrado". Testado nas Tasks 2 e 3.
4. **Checkout enviado duas vezes com "salvar endereço" marcado, perfil já preenchido:** o endereço não é duplicado, telefone e CPF já existentes no perfil não são sobrescritos, e falha ao salvar não derruba o pedido. Testado nas Tasks 3 e 11.
5. **Troca de senha com a senha atual errada, ou confirmação diferente:** mensagem clara, nada é alterado e a sessão continua. Depois de trocar, o cookie é renovado com o token novo (a troca revoga os tokens antigos), e o cliente continua logado. Testado na Task 10.

```ts
import type { z } from 'zod'

/** Primeira mensagem de cada campo de primeiro nível, para exibir embaixo do input. */
export function fieldErrors(error: z.ZodError): Record<string, string> {
  const errors: Record<string, string> = {}
  for (const issue of error.issues) {
    const key = issue.path[0]
    if (typeof key === 'string' && !(key in errors)) errors[key] = issue.message
  }
  return errors
}
```

```ts
import { z } from 'zod'
import { checkoutAddressSchema } from './checkout'
import { isValidCpf, normalizeCpf } from './cpf'
import { isValidPhone, normalizePhone } from './phone'

export const MAX_ADDRESSES = 10

/** Regra da spec: 8+ caracteres com letra e número. Devolve a mensagem do problema ou null. */
export function passwordProblem(password: string): string | null {
  if (password.length < 8) return 'Use pelo menos 8 caracteres.'
  if (password.length > 128) return 'Senha muito longa.'
  if (!/[A-Za-z]/.test(password) || !/\d/.test(password)) return 'Use letras e números.'
  return null
}

const name = z.string().trim().min(1, 'Obrigatório').max(80, 'Muito longo')

/** Campo opcional só de dígitos: vazio vira null, preenchido precisa ser válido. */
const optionalDigits = (
  normalize: (input: string) => string,
  isValid: (input: string) => boolean,
  message: string,
) =>
  z
    .string()
    .transform(normalize)
    .refine((value) => value === '' || isValid(value), message)
    .transform((value) => value || null)

export const signUpSchema = z.object({
  name,
  marketingConsent: z.boolean(),
  acceptTerms: z.literal(true, { error: 'Aceite os termos para continuar.' }),
})
export type SignUpInput = z.output<typeof signUpSchema>

export const profileSchema = z.object({
  name,
  phone: optionalDigits(normalizePhone, isValidPhone, 'Telefone inválido'),
  cpf: optionalDigits(normalizeCpf, isValidCpf, 'CPF inválido'),
  marketingConsent: z.boolean(),
})
export type ProfileInput = z.output<typeof profileSchema>

export const addressInputSchema = checkoutAddressSchema.extend({
  label: z.string().trim().max(30, 'Muito longo'),
  isDefault: z.boolean(),
})
export type AddressInput = z.output<typeof addressInputSchema>
export type SavedAddress = AddressInput & { id: string }
```

```ts
import 'server-only'
import { MAX_ADDRESSES, type AddressInput, type SavedAddress } from '@/lib/account'
import type { CheckoutAddress } from '@/lib/checkout'
import { fail, ok, type Result } from '@/lib/result'

const NOT_FOUND = fail('not_found', 'Endereço não encontrado.')

/** Garante exatamente um padrão: o preferido, senão o atual, senão o primeiro. */
function withSingleDefault(list: SavedAddress[], preferred: string | null): SavedAddress[] {
  const target =
    (preferred && list.some((a) => a.id === preferred) ? preferred : null) ??
    list.find((a) => a.isDefault)?.id ??
    list[0]?.id
  return list.map((a) => ({ ...a, isDefault: a.id === target }))
}

export function addAddress(
  list: SavedAddress[],
  input: AddressInput,
  id: string,
): Result<SavedAddress[]> {
  if (list.length >= MAX_ADDRESSES) {
    return fail('address_limit', `Você pode salvar até ${MAX_ADDRESSES} endereços.`)
  }
  return ok(withSingleDefault([...list, { ...input, id }], input.isDefault ? id : null))
}

export function updateAddress(
  list: SavedAddress[],
  id: string,
  input: AddressInput,
): Result<SavedAddress[]> {
  if (!list.some((a) => a.id === id)) return NOT_FOUND
  const next = list.map((a) => (a.id === id ? { ...input, id } : a))
  return ok(withSingleDefault(next, input.isDefault ? id : null))
}

export function removeAddress(list: SavedAddress[], id: string): SavedAddress[] {
  return withSingleDefault(
    list.filter((a) => a.id !== id),
    null,
  )
}

export function setDefaultAddress(list: SavedAddress[], id: string): Result<SavedAddress[]> {
  if (!list.some((a) => a.id === id)) return NOT_FOUND
  return ok(withSingleDefault(list, id))
}

const norm = (value: string) => value.trim().toLowerCase()

export function sameAddress(a: CheckoutAddress, b: CheckoutAddress): boolean {
  return (
    a.cep === b.cep &&
    norm(a.street) === norm(b.street) &&
    norm(a.number) === norm(b.number) &&
    norm(a.complement) === norm(b.complement)
  )
}
```

```ts
type Change = (user: UserDoc) => Result<Partial<UserDoc>>

/** Lê, decide e grava o perfil inteiro numa transação (sem perder edições simultâneas). */
async function mutateUser(uid: string, now: Date, change: Change): Promise<Result<UserDoc>> {
  const ref = users().doc(uid)
  return db().runTransaction(async (tx) => {
    const user = (await tx.get(ref)).data()
    if (!user) return fail('not_found', 'Conta não encontrada.')
    const patch = change(user)
    if (!patch.ok) return patch
    const next: UserDoc = { ...user, ...patch.data, updatedAt: now }
    tx.set(ref, next)
    return ok(next)
  })
}

const withAddresses = (result: Result<Address[]>): Result<Partial<UserDoc>> =>
  result.ok ? ok({ addresses: result.data }) : result

export function saveProfile(uid: string, input: ProfileInput, now: Date) {
  return mutateUser(uid, now, (user) =>
    ok({
      name: input.name,
      phone: input.phone,
      cpf: input.cpf,
      marketingConsent:
        user.marketingConsent.value === input.marketingConsent
          ? user.marketingConsent
          : { value: input.marketingConsent, at: now },
    }),
  )
}

export function addUserAddress(uid: string, input: AddressInput, now: Date) {
  return mutateUser(uid, now, (user) =>
    withAddresses(addAddress(user.addresses, input, randomUUID())),
  )
}

export function updateUserAddress(uid: string, id: string, input: AddressInput, now: Date) {
  return mutateUser(uid, now, (user) => withAddresses(updateAddress(user.addresses, id, input)))
}

export function removeUserAddress(uid: string, id: string, now: Date) {
  return mutateUser(uid, now, (user) => ok({ addresses: removeAddress(user.addresses, id) }))
}

export function setDefaultUserAddress(uid: string, id: string, now: Date) {
  return mutateUser(uid, now, (user) => withAddresses(setDefaultAddress(user.addresses, id)))
}

/** Depois de um pedido: completa o perfil sem sobrescrever o que o cliente já editou. */
export function rememberCheckoutDetails(
  uid: string,
  details: { phone: string; cpf: string; address: CheckoutAddress | null },
  now: Date,
) {
  return mutateUser(uid, now, (user) => {
    const { address } = details
    const added =
      address && !user.addresses.some((saved) => sameAddress(saved, address))
        ? addAddress(user.addresses, { ...address, label: '', isDefault: false }, randomUUID())
        : null
    return ok({
      phone: user.phone ?? details.phone,
      cpf: user.cpf ?? details.cpf,
      // Lista cheia: o pedido segue e o endereço só não é salvo.
      addresses: added?.ok ? added.data : user.addresses,
    })
  })
}
```

```ts
'use server'

import { redirect } from 'next/navigation'
import { signUpSchema } from '@/lib/account'
import { fail, ok, type Result } from '@/lib/result'
import { createSession, destroySession } from '@/server/auth/session'
import { saveProfile } from '@/server/db/users'
import { clientIp, rateLimit } from '@/server/ratelimit'

const INVALID = fail('invalid_input', 'Requisição inválida.')
const LIMITED = fail('rate_limited', 'Muitas tentativas. Aguarde um minuto.')

function isIdToken(value: unknown): value is string {
  return typeof value === 'string' && value.length > 0 && value.length <= 4096
}

export async function signInAction(idToken: string): Promise<Result<null>> {
  if (!isIdToken(idToken)) return INVALID
  const ip = await clientIp()
  if (!(await rateLimit(`signin:${ip}`, { limit: 10, windowSec: 60 }))) return LIMITED
  const session = await createSession(idToken)
  return session.ok ? ok(null) : session
}

export async function signUpAction(idToken: string, input: unknown): Promise<Result<null>> {
  if (!isIdToken(idToken)) return INVALID
  const parsed = signUpSchema.safeParse(input)
  if (!parsed.success) {
    return fail('invalid_input', parsed.error.issues[0]?.message ?? 'Confira os dados.')
  }
  const ip = await clientIp()
  if (!(await rateLimit(`signup:${ip}`, { limit: 5, windowSec: 600 }))) return LIMITED

  const session = await createSession(idToken)
  if (!session.ok) return session
  try {
    const { name, marketingConsent } = parsed.data
    await saveProfile(session.data.uid, { name, phone: null, cpf: null, marketingConsent }, new Date())
  } catch (error) {
    // A conta e a sessão já existem; o nome pode ser corrigido no perfil.
    console.error('signUp: falha ao gravar o perfil', { uid: session.data.uid, error })
  }
  return ok(null)
}

export async function signOutAction(): Promise<void> {
  await destroySession()
  redirect('/')
}
```

```tsx
'use client'

import {
  createUserWithEmailAndPassword,
  sendEmailVerification,
  signOut,
} from 'firebase/auth'
import Link from 'next/link'
import { useRouter } from 'next/navigation'
import { useState } from 'react'
import { Button, Checkbox, TextField } from '@/components/ui'
import { passwordProblem, signUpSchema } from '@/lib/account'
import { clientAuth } from '@/lib/firebase-client'
import { fieldErrors } from '@/lib/form-errors'
import { signUpAction } from './actions'
import { authErrorCode, authErrorMessage } from './error-messages'

type Errors = Partial<Record<'name' | 'password' | 'acceptTerms', string>>

export function SignUpForm() {
  const router = useRouter()
  const [name, setName] = useState('')
  const [email, setEmail] = useState('')
  const [password, setPassword] = useState('')
  const [acceptTerms, setAcceptTerms] = useState(false)
  const [marketingConsent, setMarketingConsent] = useState(false)
  const [errors, setErrors] = useState<Errors>({})
  const [error, setError] = useState<string | null>(null)
  const [pending, setPending] = useState(false)

  async function submit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault()
    setError(null)
    const parsed = signUpSchema.safeParse({ name, marketingConsent, acceptTerms })
    const found: Errors = parsed.success ? {} : fieldErrors(parsed.error)
    const weak = passwordProblem(password)
    if (weak) found.password = weak
    setErrors(found)
    if (!parsed.success || weak) return

    setPending(true)
    try {
      const auth = clientAuth()
      const { user } = await createUserWithEmailAndPassword(auth, email.trim(), password)
      // Sem a verificação o cliente só perde o vínculo de pedidos antigos: não bloqueia o cadastro.
      await sendEmailVerification(user, {
        url: `${window.location.origin}/entrar?next=/conta&confirmado=1`,
      }).catch(() => {})
      const result = await signUpAction(await user.getIdToken(), parsed.data)
      await signOut(auth)
      if (!result.ok) {
        setError(result.message)
        return
      }
      router.replace('/conta')
      router.refresh()
    } catch (err) {
      setError(authErrorMessage(authErrorCode(err), 'Não foi possível criar a conta. Tente de novo.'))
    } finally {
      setPending(false)
    }
  }

  return (
    <form className="flex flex-col gap-5" onSubmit={submit} noValidate>
      <TextField label="Nome" autoComplete="name" value={name} error={errors.name} onValue={setName} />
      <TextField
        label="E-mail"
        type="email"
        autoComplete="email"
        required
        value={email}
        onValue={setEmail}
      />
      <TextField
        label="Senha"
        type="password"
        autoComplete="new-password"
        value={password}
        error={errors.password}
        onValue={setPassword}
      />
      <div className="flex flex-col gap-2">
        <Checkbox
          checked={acceptTerms}
          onChange={(event) => setAcceptTerms(event.target.checked)}
          label={
            <>
              Li e aceito os{' '}
              <Link href="/legal/termos-de-uso" className="underline" target="_blank">
                termos de uso
              </Link>{' '}
              e a{' '}
              <Link href="/legal/politica-de-privacidade" className="underline" target="_blank">
                política de privacidade
              </Link>
              .
            </>
          }
        />
        {errors.acceptTerms ? (
          <p className="font-mono text-[10px] text-danger">{errors.acceptTerms}</p>
        ) : null}
      </div>
      <Checkbox
        checked={marketingConsent}
        onChange={(event) => setMarketingConsent(event.target.checked)}
        label="Quero receber novidades e lançamentos por e-mail."
      />
      {error ? (
        <p
          role="alert"
          className="border border-danger/20 bg-danger/10 p-3 text-center text-xs text-danger"
        >
          {error}
        </p>
      ) : null}
      <Button type="submit" size="lg" loading={pending}>
        Criar conta
      </Button>
    </form>
  )
}
```

```ts
'use server'

import { redirect } from 'next/navigation'
import { fail, type Result } from '@/lib/result'
import { destroySession, getAuthAccount, requireUser } from '@/server/auth/session'

/**
 * O cookie guarda `email_verified` do momento do login. Depois de confirmar o e-mail,
 * um login novo atualiza o cookie e vincula os pedidos feitos sem conta.
 */
export async function confirmEmailAction(): Promise<Result<null>> {
  const user = await requireUser()
  const account = await getAuthAccount(user.uid)
  if (!account.emailVerified) {
    return fail(
      'not_verified',
      'Ainda não recebemos a confirmação. Abra o link do e-mail e tente de novo.',
    )
  }
  await destroySession()
  redirect('/entrar?next=/conta&confirmado=1')
}
```

```tsx
'use client'

import { useRouter } from 'next/navigation'
import { useState, useTransition } from 'react'
import { Button, Checkbox, TextField } from '@/components/ui'
import { profileSchema } from '@/lib/account'
import { formatCpf } from '@/lib/cpf'
import { fieldErrors } from '@/lib/form-errors'
import { formatPhone } from '@/lib/phone'
import { updateProfileAction } from './actions'

type Values = { name: string; phone: string; cpf: string; marketingConsent: boolean }

export function ProfileForm({ initial }: { initial: Values }) {
  const router = useRouter()
  const [values, setValues] = useState<Values>({
    ...initial,
    phone: formatPhone(initial.phone),
    cpf: formatCpf(initial.cpf),
  })
  const [errors, setErrors] = useState<Record<string, string>>({})
  const [status, setStatus] = useState<{ ok: boolean; text: string } | null>(null)
  const [pending, start] = useTransition()
  const set = (patch: Partial<Values>) => setValues((current) => ({ ...current, ...patch }))

  function submit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault()
    setStatus(null)
    const parsed = profileSchema.safeParse(values)
    setErrors(parsed.success ? {} : fieldErrors(parsed.error))
    if (!parsed.success) return
    start(async () => {
      const result = await updateProfileAction(values)
      setStatus(result.ok ? { ok: true, text: 'Dados salvos.' } : { ok: false, text: result.message })
      if (result.ok) router.refresh()
    })
  }

  return (
    <form onSubmit={submit} noValidate className="flex max-w-xl flex-col gap-5">
      <TextField
        label="Nome completo"
        autoComplete="name"
        value={values.name}
        error={errors.name}
        onValue={(name) => set({ name })}
      />
      <div className="grid gap-4 sm:grid-cols-2">
        <TextField
          label="Telefone"
          type="tel"
          autoComplete="tel-national"
          value={values.phone}
          error={errors.phone}
          onValue={(phone) => set({ phone: formatPhone(phone) })}
        />
        <TextField
          label="CPF"
          inputMode="numeric"
          value={values.cpf}
          error={errors.cpf}
          onValue={(cpf) => set({ cpf: formatCpf(cpf) })}
        />
      </div>
      <Checkbox
        checked={values.marketingConsent}
        onChange={(event) => set({ marketingConsent: event.target.checked })}
        label="Quero receber novidades e lançamentos por e-mail."
      />
      {status ? (
        <p role="status" className={status.ok ? 'text-xs text-success' : 'text-xs text-danger'}>
          {status.text}
        </p>
      ) : null}
      <Button type="submit" loading={pending} className="self-start">
        Salvar
      </Button>
    </form>
  )
}
```

```tsx
'use client'

import { useRouter } from 'next/navigation'
import { useState, useTransition } from 'react'
import { Badge, Button, Checkbox, TextField } from '@/components/ui'
import {
  AddressFields,
  EMPTY_ADDRESS,
  type AddressErrors,
  type AddressValues,
} from '@/features/checkout/address-fields'
import { lookupCepAction } from '@/features/checkout/actions'
import { addressInputSchema, MAX_ADDRESSES, type SavedAddress } from '@/lib/account'
import { formatCep, normalizeCep } from '@/lib/cep'
import { fieldErrors } from '@/lib/form-errors'
import { deleteAddressAction, saveAddressAction, setDefaultAddressAction } from './actions'

type Draft = AddressValues & { label: string; isDefault: boolean }
type Editing = { id: string | null; draft: Draft } | null

function AddressForm({
  editing,
  onCancel,
  onSaved,
}: {
  editing: NonNullable<Editing>
  onCancel: () => void
  onSaved: () => void
}) {
  const [draft, setDraft] = useState<Draft>(editing.draft)
  const [errors, setErrors] = useState<AddressErrors & { label?: string }>({})
  const [message, setMessage] = useState<string | null>(null)
  const [pending, start] = useTransition()
  const patch = (next: Partial<Draft>) => setDraft((current) => ({ ...current, ...next }))

  function onCepChange(raw: string) {
    patch({ cep: formatCep(raw) })
    const cep = normalizeCep(raw)
    if (cep.length !== 8) return
    start(async () => {
      const found = await lookupCepAction(cep)
      if (found.ok) patch(found.data)
    })
  }

  function submit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault()
    setMessage(null)
    const parsed = addressInputSchema.safeParse(draft)
    setErrors(parsed.success ? {} : fieldErrors(parsed.error))
    if (!parsed.success) return
    start(async () => {
      const result = await saveAddressAction(editing.id, draft)
      if (result.ok) onSaved()
      else setMessage(result.message)
    })
  }

  return (
    <form onSubmit={submit} noValidate className="flex flex-col gap-4 border border-line p-5">
      <TextField
        label="Apelido (opcional)"
        placeholder="Casa, trabalho…"
        value={draft.label}
        error={errors.label}
        onValue={(label) => patch({ label })}
      />
      <AddressFields value={draft} errors={errors} onChange={patch} onCepChange={onCepChange} />
      <Checkbox
        checked={draft.isDefault}
        onChange={(event) => patch({ isDefault: event.target.checked })}
        label="Usar como endereço padrão"
      />
      {message ? (
        <p role="alert" className="text-xs text-danger">
          {message}
        </p>
      ) : null}
      <div className="flex gap-3">
        <Button type="submit" loading={pending}>
          Salvar endereço
        </Button>
        <Button variant="ghost" onClick={onCancel}>
          Cancelar
        </Button>
      </div>
    </form>
  )
}

export function AddressBook({ addresses }: { addresses: SavedAddress[] }) {
  const router = useRouter()
  const [editing, setEditing] = useState<Editing>(null)
  const [message, setMessage] = useState<string | null>(null)
  const [pending, start] = useTransition()

  function run(action: () => Promise<{ ok: boolean; message?: string }>) {
    setMessage(null)
    start(async () => {
      const result = await action()
      if (!result.ok) setMessage(result.message ?? 'Algo deu errado. Tente novamente.')
      router.refresh()
    })
  }

  const saved = () => {
    setEditing(null)
    router.refresh()
  }

  return (
    <div className="flex max-w-2xl flex-col gap-6">
      {message ? (
        <p role="alert" className="text-xs text-danger">
          {message}
        </p>
      ) : null}
      <ul className="flex flex-col gap-4">
        {addresses.map((address) => (
          <li key={address.id} className="flex flex-col gap-3 border border-line p-5">
            <div className="flex items-center gap-3">
              <span className="text-xs font-bold tracking-widest uppercase">
                {address.label || 'Endereço'}
              </span>
              {address.isDefault ? <Badge tone="success">Padrão</Badge> : null}
            </div>
            <p className="text-xs leading-relaxed text-muted">
              {address.street}, {address.number}
              {address.complement ? ` — ${address.complement}` : ''}
              <br />
              {address.neighborhood} · {address.city}/{address.state} · CEP{' '}
              {formatCep(address.cep)}
            </p>
            <div className="flex flex-wrap gap-2">
              <Button
                variant="secondary"
                size="sm"
                disabled={pending}
                onClick={() =>
                  setEditing({ id: address.id, draft: { ...address, cep: formatCep(address.cep) } })
                }
              >
                Editar
              </Button>
              {address.isDefault ? null : (
                <Button
                  variant="ghost"
                  size="sm"
                  disabled={pending}
                  onClick={() => run(() => setDefaultAddressAction(address.id))}
                >
                  Tornar padrão
                </Button>
              )}
              <Button
                variant="ghost"
                size="sm"
                disabled={pending}
                onClick={() => {
                  if (window.confirm('Excluir este endereço?')) {
                    run(() => deleteAddressAction(address.id))
                  }
                }}
              >
                Excluir
              </Button>
            </div>
          </li>
        ))}
      </ul>

      {editing ? (
        <AddressForm
          key={editing.id ?? 'new'}
          editing={editing}
          onCancel={() => setEditing(null)}
          onSaved={saved}
        />
      ) : addresses.length < MAX_ADDRESSES ? (
        <Button
          variant="secondary"
          className="self-start"
          onClick={() =>
            setEditing({
              id: null,
              draft: { ...EMPTY_ADDRESS, label: '', isDefault: addresses.length === 0 },
            })
          }
        >
          Novo endereço
        </Button>
      ) : (
        <p className="text-xs text-muted">Você chegou ao limite de {MAX_ADDRESSES} endereços.</p>
      )}
    </div>
  )
}
```

```tsx
'use client'

import { signInWithEmailAndPassword, signOut, updatePassword } from 'firebase/auth'
import { useRouter } from 'next/navigation'
import { useState } from 'react'
import { Button, TextField } from '@/components/ui'
import { signInAction } from '@/features/auth/actions'
import { authErrorCode, authErrorMessage } from '@/features/auth/error-messages'
import { passwordProblem } from '@/lib/account'
import { clientAuth } from '@/lib/firebase-client'

type Errors = Partial<Record<'current' | 'next' | 'confirm', string>>
const WRONG = ['auth/invalid-credential', 'auth/wrong-password']

export function ChangePasswordForm({ email }: { email: string }) {
  const router = useRouter()
  const [current, setCurrent] = useState('')
  const [next, setNext] = useState('')
  const [confirm, setConfirm] = useState('')
  const [errors, setErrors] = useState<Errors>({})
  const [status, setStatus] = useState<{ ok: boolean; text: string } | null>(null)
  const [pending, setPending] = useState(false)

  async function submit(event: React.FormEvent<HTMLFormElement>) {
    event.preventDefault()
    setStatus(null)
    const found: Errors = {}
    const weak = passwordProblem(next)
    if (weak) found.next = weak
    else if (next === current) found.next = 'Escolha uma senha diferente da atual.'
    if (confirm !== next) found.confirm = 'As senhas não conferem.'
    if (!current) found.current = 'Obrigatório'
    setErrors(found)
    if (Object.keys(found).length > 0) return

    setPending(true)
    const auth = clientAuth()
    try {
      const { user } = await signInWithEmailAndPassword(auth, email, current)
      await updatePassword(user, next)
      // A troca revoga os tokens antigos: o cookie precisa nascer do token novo.
      const session = await signInAction(await user.getIdToken(true))
      await signOut(auth)
      if (!session.ok) {
        router.replace('/entrar?next=/conta/seguranca')
        return
      }
      setCurrent('')
      setNext('')
      setConfirm('')
      setStatus({ ok: true, text: 'Senha alterada.' })
      router.refresh()
    } catch (err) {
      const code = authErrorCode(err)
      setStatus({
        ok: false,
        text: WRONG.includes(code)
          ? 'Senha atual incorreta.'
          : (authErrorMessage(code, 'Não foi possível trocar a senha. Tente de novo.') ?? ''),
      })
    } finally {
      setPending(false)
    }
  }

  return (
    <form onSubmit={submit} noValidate className="flex max-w-sm flex-col gap-5">
      <TextField
        label="Senha atual"
        type="password"
        autoComplete="current-password"
        value={current}
        error={errors.current}
        onValue={setCurrent}
      />
      <TextField
        label="Nova senha"
        type="password"
        autoComplete="new-password"
        value={next}
        error={errors.next}
        onValue={setNext}
      />
      <TextField
        label="Repita a nova senha"
        type="password"
        autoComplete="new-password"
        value={confirm}
        error={errors.confirm}
        onValue={setConfirm}
      />
      {status ? (
        <p role="status" className={status.ok ? 'text-xs text-success' : 'text-xs text-danger'}>
          {status.text}
        </p>
      ) : null}
      <Button type="submit" loading={pending} className="self-start">
        Trocar senha
      </Button>
    </form>
  )
}
```

```ts
/** Completa a conta com o que foi digitado no checkout. Nunca derruba o pedido. */
async function remember(uid: string, input: unknown): Promise<void> {
  const parsed = rememberSchema.safeParse(input)
  if (!parsed.success) return
  const { customer, address, saveAddress } = parsed.data
  try {
    await rememberCheckoutDetails(
      uid,
      { phone: customer.phone, cpf: customer.cpf, address: saveAddress ? address : null },
      new Date(),
    )
  } catch (error) {
    console.error('createOrder: falha ao guardar dados na conta', { uid, error })
  }
}
```

```markdown
### Decisões da Fase 4 (2026-10-18)
- **Vínculo guest → conta** acontece dentro de `createSession` sempre que o ID token traz `email_verified` (login com Google, login depois de confirmar o e-mail). Falha no vínculo não impede o login.
- **Cookie desatualizado:** o session cookie guarda a verificação do momento do login. O aviso em `/conta` tem "Já confirmei", que consulta o Firebase e pede um novo login (`/entrar?confirmado=1`).
- **Sem reenvio de verificação nesta fase:** sem e-mail verificado, o cliente só perde o vínculo automático de pedidos antigos. Reenviar fica para quando o domínio do Resend existir.
- **Troca de senha** no navegador: reautentica com a senha atual, `updatePassword` e cookie novo a partir de `getIdToken(true)` (a troca revoga os tokens antigos).
- **Endereços:** até 10 por conta, sempre exatamente um padrão (regra pura em `server/domain/addresses.ts`).
- **Checkout logado:** pré-preenche com o endereço padrão, permite escolher entre os salvos e tem "Salvar este endereço na minha conta" (marcado por padrão quando não há endereços). Telefone e CPF vão para o perfil só se estiverem vazios. Salvar dados da conta nunca derruba o pedido.
- **Rotas:** `/conta` (pedidos, com link para `/pedido/[token]`), `/conta/enderecos`, `/conta/perfil`, `/conta/seguranca`, dentro do grupo `(loja)`.
```
